# 📋 Work Items (GitHub Projects)

Todo el trabajo se organiza en el project **[GDG Tracks](https://github.com/orgs/GDG-Tarija/projects/1)**. Cada tarea es un **WI** (un issue de GitHub) y su número es el que va en el nombre de la rama.

## Estados

```
Backlog → Ready → In progress → In review → Done
```

| Estado | Significa |
| --- | --- |
| **Backlog** | Idea o tarea pendiente, todavía sin definir del todo |
| **Ready** | Está clara y lista para que alguien la tome |
| **In progress** | Alguien la está trabajando (tiene rama) |
| **In review** | Tiene un PR abierto esperando aprobación |
| **Done** | El PR se mergeó (pasa sola al usar `Closes #N`) |

## Tomar una tarea

1. Elige un WI en **Ready** y asígnatelo (**Assignees**).
2. Muévelo a **In progress** y crea tu rama ([ver formato](branches.md)).
3. Al abrir el PR, muévelo a **In review**.

## Crear un WI

- Usa un título corto y claro. Puede estar en español o inglés.
- Si nace como *draft* en el project, conviértelo en issue (**Convert to issue**) para que tenga número.
- Opcional: **Priority** (`P0` urgente → `P2` puede esperar) y **Size** (`XS` → `XL`).
- Si es parte de un evento, ponlo en el título o como label (por ejemplo, `DevFest 2026`).
