# 👋 GDG Tarija

Somos el capítulo de **Google Developer Groups** en Tarija, Bolivia: una comunidad de voluntarios que organiza eventos para developers desde 2013 (DevFest, Google I/O Extended, International Women's Day, Build with AI, talleres y más).

🌐 [gdgtarija.com](https://gdgtarija.com) · 📅 [eventos.gdgtarija.com](https://eventos.gdgtarija.com) · ✉️ gdgtarija@gmail.com
